# Незалежна перевірка механізму адаптації та порога втручання

Історична серія випробувала всі 32 маски початкової бази 30/90/1. Тут сім механізмів перевіряються на двох підібраних базах 15/90/1 та 15/100/1. Архівні задачі, збережені точні еталони й код операторів походять із версії f71aa9fea528e875de97f4194c77780eba8d0e9b репозиторію ChepaMaksym/GA-article-test. Технічні випадки поза добором. Повний запис перевіряє окрема реалізація відтворення з шістьма станами генераторів. Точний оптимум доступний зовнішньому обробнику.

## Добір

Задачі s050–s059, класи UC, WC, SC. По три повторення 150001–150003, підготовка 150000, спільні банки. Сто тисяч обчислень включають початок. За кожної бази k2, k3 та A2 виконуються один раз на початок. A1 (популяція), A3 (мутація), A4 (відбір), A5 (елітизм), A6 (відбір та елітизм), A7 (усі правила) отримують пороги 70, 145 і 280. Обсяг становить 3780 результатів. Для A2 і A7 схрещування 100% застосовується у першому поколінні, наступні значення визначає історична формула 0,1 + 0,8R.

Два критерії: кінцеве відставання у відсотках та обмежене середнє число обчислень до першого досягнення 93% оптимуму. Початок нумерується з 1, останнє обчислення включено, недосягнення має значення 100000 й окрему ознаку. Додатково 95% і 99%. Усереднення: повторення, задача, сімейство. На кожній базі для кожного критерію обрати найкращу пару механізму й порога; за точних нічиїх порівняти другий показник, кількість активних правил, номер A та поріг.

## Сильний сталий контроль і момент адаптації

Сталі рівні для кожного фіналіста задає design.py. Для A6 перевіряються 20 пар, для A7 по 24 спільні конфігурації, зафіксовані в registered.json до пошуку. Для відібраного механізму, залежного від застою, перевірити h = 2, 5, 10, 20, 50; H₀=h(μ₀−e₀). Для бази 15/1 це 28, 70, 140, 280 і 700. Історичний контроль 145 окремий. При μ=15 та e=1 умова 140 спрацьовує на 140, умова 145 на 154 за відсутності поліпшень. Динамічну гілку відкривати лише за фактично змінного числа нових кандидатів; поріг дорівнює h, помноженому на квоту щойно завершеного покоління. Записувати події та фактичні зміни окремо. Для бази 90% провести місток μ=15,30 × H=70,145 для відібраного залежного механізму (якість, потім швидкість). Донор відтворює повний вектор керованих параметрів за поколіннями; його генератори пошуку окремі.

До відкриття даних зафіксувати фіналістів, їхні правила, сильні сталі контроли та ідентифікатори входів. Для кожної бази й критерію контролі k2, k3, найкращий сталий, донорський розклад і той самий механізм із фіксованим H=145. У п’ятій парі всі інші умови однакові. Для A2 ця пара незастосовна, для вибраного H=145 тотожна. Тотожні фізичні запуски виконувати один раз. Нижня межа вище нуля підтримує перевагу у відповідній парі. Вироджені оцінки подавати описово.

Окрема родина до 20 порівнянь, одиниця повторної вибірки — ціла відомість. Для ГА й точного динамічного програмування виміряти час до повернення готового вантажу в одному послідовному середовищі. Швидкість до ретроспективної цілі обліковувати за обчисленнями. Дані синтетичні.
