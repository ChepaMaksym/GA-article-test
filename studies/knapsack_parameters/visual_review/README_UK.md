# Рисунки з дослідницькими питаннями

Сім рисунків побудовано з незмінних результатів. П'ять призначено для основного викладу, два для діагностичних додатків. Кожний рисунок має питання, коротку відповідь і обмеження.

Перевірений [запуск побудови](https://github.com/ChepaMaksym/GA-article-test/actions/runs/38073372210) завершився успішно: 23 тести, сім PNG і сім векторних PDF. Нових запусків ГА, точних розв'язувачів або бутстрепу немає.

Рисунки відповідають на питання про локальність, первинні ефекти, внесок сімейств, залежність від комбінації параметрів та відставання від точного оптимуму. Додатки пояснюють стійкість популяційного ефекту й зміни популяції без нового рекорду. Адаптивне порівняння на рюкзаку не зображається як виконане.

Див. [контракт подання](PROTOCOL_UK.md) та [компактний реєстр походження](evidence/run-38073372210/receipt.json). Повні експорти доступні в CI; потрібні рисунки й диплом збережені локально. `source-file-manifest.json` описує повний CI-пакет, а не перелік файлів компактного Git-каталогу.

Повторна побудова дозволена лише в GitHub Actions за маркером `[knapsack-figures:render]`, на точному SHA цієї гілки. Локально не запускати модуль або тести. Код пошуку, первинні протоколи й історичні результати не змінено.
