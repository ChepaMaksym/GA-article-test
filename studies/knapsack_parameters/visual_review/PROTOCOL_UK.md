# Показова база дослідження: питання, рисунок, відповідь

Ідентифікатор: `GA-KNAPSACK-QUESTION-FIGURES-V1`.

Це зміна подання вже переглянутих результатів, а не попередня реєстрація нової гіпотези. Первинні протоколи, числа, довірчі інтервали й історичні файли залишаються незмінними.

## Джерела

- Завершена основна серія: run `37793424917`, реалізація `5fe14fad17368dd94faa86cc0d6138361d3722cf`.
- Завершений вторинний розбір: run `38031512934`, реалізація `6cbc73d8da8b26e9b96f98972db4958a618dab0e`.
- Незалежний сертифікат UC-s000: run `37637475385`; центр 46510, точний оптимум 46537, усі 5050 сусідів.
- Усі входи перевіряються за зафіксованими SHA256, а не лише за назвами файлів.

## П'ять основних питань

1. Чому UC-s000 є локальним, але не глобальним максимумом? Показати всі одно- й двобітні сусіди у координатах «вага мінус місткість» та «цінність мінус цінність центра». Межі нуля мають математичний зміст. Трьохбітний оптимальний свідок показати окремо, не як члена цього сусідства. Додати явно позначене наближення без вилучення повного огляду.
2. Який параметр має встановлений напрям ефекту? Один рисунок із чотирма незмінними первинними оцінками й інтервалами 98,75%, спільною шкалою відсоткових пунктів і нульовою вертикаллю.
3. Чи популяція 50 краща за 10 у всіх сімействах? Парні сімейні частоти виходу, діагональ рівності. Спочатку усереднити повторення задачі за дев'ятьма налаштуваннями інших параметрів, потім задачі сімейства. Відновлена різниця має збігатися з історичним сімейним контрастом. Це описове подання, без нових інтервалів або p-значень.
4. Чи вплив мутації залежить від схрещування й популяції? Три панелі для N=10,30,50 з однаковою шкалою; лише 27 збережених сімейно-зважених локальних частот. Категорії мутації не подавати як неперервну перевірену модель.
5. Що означає відсутність виходу? Наперед обрані шість UC-s000, seed 51001: відставання рекорду від точного оптимуму. Для локальних трьох запусків явно показати розрив 27 і збіг траєкторій. Рекорд відображати лише в збережених контрольних точках, без вигаданих моментів поліпшення між ними.

У додатках: стійкість популяційного контрасту без одного сімейства; середня цінність допустимих особин і різноманітність локальних запусків. Вони відповідають питанням про стійкість ефекту та зміну популяції за плоского рекорду.

## Оформлення й перевірка

Білий фон, чорні/сірі елементи, різні маркери й стилі ліній. Ширина рисунка 6,8 дюйма, підписи не менші 11 пунктів при кінцевому масштабі, максимум три панелі. Зберігати PNG, векторний PDF, таблиці використаних точок і компактний паспорт «питання → відповідь → обмеження → джерело».

У CI перевірити контрольні суми, повноту джерел, 5050 неповторних сусідів, числа сертифіката, відстань трьохбітного свідка, одиниці виміру, сімейне усереднення, незмінність первинних інтервалів і відсутність вигаданих популяційних точок незавершеного покоління.

Нові GA-запуски, точні розв'язувачі, бутстреп і адаптивне порівняння не виконуються. Усі перевірки й наукові рисунки виконуються лише через GitHub Actions на точному SHA в гілці рюкзака. Один запуск обмежено десятьма runner-хвилинами. Повторення допускається лише для виправлення технічного збою, без зміни наукових входів.

Графіки не доводять універсальності налаштувань. Нульова спостережена частота не означає нульової ймовірності. Рисунок сусідів є двовимірним поданням сертифіката, не повним ландшафтом ста бітів. Адаптивної серії на рюкзаку немає: порівняльний рисунок для неї не створюється.
