# Підготовка перевірки відбору на обраних початкових параметрах

Статус: код і протокол готуються; нове порівняння не виконане. Числових висновків цього етапу немає.

Наукові умови та обмеження наведено в PROTOCOL.md; первинний допуск — ADMISSION.md. Ідентичності визначає configuration.py. Історичні реалізації й результати зберігаються.

## Програма

program/ga_core/engine.py містить один активний цикл еволюції. Публічний інтерфейс run_ga збережено. Новий контракт calibrated-selection-v1 задає явні початкові параметри й дозволяє змінювати тільки розмір відбіркової групи. Попередні контракти не розширено.

search.py передає ядру лише задачу, банк початкових особин, контролер, генератори й граничну кількість нових оцінювань. OPT та сертифікати доступні зовнішній перевірці. preparation.py відповідає за походження входів, банки й два незалежні точні еталони. verification.py самостійно відновлює оператори, оцінки, популяції, керування та випадкові стани без імпорту виробничого ядра.

resources.py обмежує дерево процесів контейнера половиною ефективно доступних CPU та RAM. execution.py зберігає перевірені випадки окремо. observations.py обчислює показники тільки з журналів; обробка не викликає пошук.

## Дозволи й виконання

Усі тести, числові перевірки, пошук і рисунки нового порівняння виконуються тільки в GitHub Actions. Локально готуються файли та перевіряється синтаксис. Не встановлюйте GITHUB_ACTIONS вручну для обходу обмеження.

Технічний workflow не запускається без нового дозволу, зафіксованого у technical_authorization.json, і відповідної окремої гілки. Технічний ліміт погоджений; він не витрачався. Виконання відкладено за пріоритетом документів. Пропозиція — 60 runner-хвилин і 2 GiB на 21 пілот, шість зіставлень, тести, підготовку й кошторис. Скорочені 210 запусків не охоплюються цим дозволом.

Після внесення погодженого дозволу пакет повторно фіксується командою підготовки seal.py --write. SHA-256 охоплюють новий код, протокол, workflow, залежності та історичні джерела. Фіксація файлів не означає успішного проходження тестів.

## Межі готовності

AST-перевірка підтверджує лише синтаксичну коректність. Програмну відповідність мають підтвердити тести й незалежне відновлення в CI. Корисність змінного відбору визначається тільки результатами основної серії. Статус магістерської чернетки та відсутні офіційні реквізити наведено в окремій папці Магістерська_робота_100_500.
