## Межі поточного результату

Три параметри GA для задачі рюкзака вже досліджували Anagun і Saraç (2006), DOI [10.1007/11751595_72](https://doi.org/10.1007/11751595_72). Загальна ідея такого порівняння не є новою. Конкретне поєднання двох початкових умов, незалежної сертифікації неглобального максимуму щодо допустимих сусідів із відстанню до двох бітів та повного факторного плану становить перевірюване дослідницьке питання, але його світового пріоритету не встановлено.

Протокол має статус `DRAFT_NOT_EXECUTED`. Хеші завантажених даних, реалізації, реєстру центрів, ідентифікатори запусків і числові результати ще відсутні. Значення `null` у метаданих не означає виконану перевірку.

## Наступний, ще не виконаний етап

Після окремої вказівки: завершення аудиту джерел і даних, замороження протоколу окремим комітом, реалізація, перевірки тільки в GitHub Actions, підготовка реєстру центрів, запуск на точному SHA та агрегація. Локально наукові алгоритми, тести, статистику й графіки результатів не запускати. Злиття гілки не виконується.
