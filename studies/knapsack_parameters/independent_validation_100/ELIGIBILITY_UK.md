# Допуск до незалежної перевірки базових параметрів

Когорта охоплює 30 задач зі 100 предметами, сімейства s060–s069, по UC, WC та SC. Індекси 33–62 відповідають порядку сімейства та типу. У попередньому аудиті входи зіставлено зі 180 історичними задачами за послідовністю предметів і за впорядкованими парами ваги та цінності. Для кожної задачі збережено два точні еталони.

Підставою для нового порівняння є завершена серія на сімействах s050–s059. Наперед обрані значення для кінцевої якості становлять 15 / 100% / 1%, для швидкості 10 / 90% / 1%. Популяція 13 за схрещування 90% не змінила жодного з двох мінімумів. Для діагностики різниці швидкості 0,067 оцінювання потрібен окремий варіант 15 / 90% / 1%.

Історичний архів входів GitHub Actions 13792676347 пов’язано із запуском 42876556319. Перевірка походження спирається на зафіксовані контрольні суми архіву, кожної задачі та її сертифікатів. Подальший допуск вимагає повторної звірки реєстрів і метаданих виконань після початкового аудиту. Підготовка входу або обчислення точного оптимуму обліковуються окремо від евристичного пошуку.

За виявлення використання когорти для добору, непоясненого виконання, дубліката або порушення походження підготовка завершується до пошуку. Висновок про незалежність стосується перевірених джерел проєкту.
