# Еволюція параметрів ГА для рюкзака

Окреме власне дослідження п’яти правил керування одним поколіннєвим генетичним алгоритмом. Протокол зареєстровано комітом `8ac7d65a3268b9ccda75d1ac5a2c34db5a7621c5` до реалізації.

Технічний етап завершено: 66 програмних перевірок без помилок і пропусків; вісім зафіксованих початків; 256/256 незалежно перевірених запусків та 1 280 000 нових оцінювань. [Пілот і зведення](https://github.com/ChepaMaksym/GA-article-test/actions/runs/40201292716) виконано на точному коміті `3ac2ba7d74a58768c11406093191365012e93d68`. Основна серія не дозволена: потрібне окреме погодження виміряного кошторису.

Усі 32 поєднання мають однаковий початок і перше покоління. Правила керують мутацією, схрещуванням, цільовим розміром наступного покоління, турніром і числом еліт. Кожне нове оцінювання входить до бюджету; завершальний префікс не змінює популяцію чи параметри.

Технічний дозвіл: до 120 runner-хвилин на перевірки, вісім початків, 256 проб і незалежне зведення. Наукові обчислення виконуються лише в зареєстрованих фазах GitHub Actions. Невідомий ресурс, відсутній дозвіл або незмінений статус історичних досліджень не підміняються успіхом.

Фактично використано 17 runner-хвилин з округленням угору для кожного виділеного завдання. Стиснені пошукові журнали становлять 81 633 225 байтів. Консервативний прогноз 28 800 запусків: 1735 runner-хвилин із резервуванням та 13 775 606 719 байтів журналів із запасом 50%. Підготовку нових точних еталонів ще не виміряно. Це кошторис, а не дозвіл виконання.

Усі п’ять правил фактично змінювали параметри в чотирьох випадкових початках повністю адаптивного варіанта. Сімейно-зважене відставання становило 2,2999% для сталого контролю та 4,9780% для спільної адаптації. Один технічний повтор не встановлює наукової переваги або стійкого погіршення. Правила після цих спостережень не змінювалися. Первинні підтверджувальні інтервали не обчислювалися.

Компактні результати, показники активності, приклади траєкторій, кошторис і свідоцтво повноти містяться в `evidence/pilot-40201292716-1/`. Реєстр ZIP, строки доступності та облік ресурсів збережено поряд. Повні кандидатні журнали до Git не додаються. Початкове зведення збережено без змін; у локальному академічному викладі нульове досягнення 99% для контрольної пари подано чисельно замість порожньої панелі.

Код і компактні докази належать цій дослідницькій гілці. Повні журнали зберігаються окремо. Локальні Word/PDF не публікуються; попередні документи та історичні ядра не змінюються.
