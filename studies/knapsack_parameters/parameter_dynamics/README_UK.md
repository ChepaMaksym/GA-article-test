# Еволюція параметрів ГА для рюкзака

Окреме власне дослідження п’яти правил керування одним поколіннєвим генетичним алгоритмом. Протокол зареєстровано комітом `8ac7d65a3268b9ccda75d1ac5a2c34db5a7621c5` до реалізації.

Основну серію завершено: 28 800/28 800 незалежно перевірених запусків, 144 млн нових оцінювань, 30 нових задач і шість первинних порівнянь. [Виконання та зведення](https://github.com/ChepaMaksym/GA-article-test/actions/runs/40205451045) відповідають точному коміту `3e28c407db41a31d251e8063b31f67c83ecc606b`. [Підсумки основної серії](RESULTS_MAIN_UK.md) розділяють підтверджені ефекти, описові показники та обмеження.

Попередній технічний етап: 66 програмних перевірок без помилок і пропусків; вісім зафіксованих початків; 256/256 незалежно перевірених запусків та 1 280 000 нових оцінювань. [Пілот і зведення](https://github.com/ChepaMaksym/GA-article-test/actions/runs/40201292716) виконано на точному коміті `3ac2ba7d74a58768c11406093191365012e93d68`.

Усі 32 поєднання мають однаковий початок і перше покоління. Правила керують мутацією, схрещуванням, цільовим розміром наступного покоління, турніром і числом еліт. Кожне нове оцінювання входить до бюджету; завершальний префікс не змінює популяцію чи параметри.

Технічний дозвіл: до 120 runner-хвилин на перевірки, вісім початків, 256 проб і незалежне зведення. Наукові обчислення виконуються лише в зареєстрованих фазах GitHub Actions. Невідомий ресурс, відсутній дозвіл або незмінений статус історичних досліджень не підміняються успіхом.

Технічний етап використав 17/120 runner-хвилин; його стиснені журнали становлять 81 633 225 байтів. Після окремого погодження основного етапу до 1800 runner-хвилин і 16 GiB фактично використано 779 хвилин та 9 070 994 983 байти журналів. Облік округлює вгору тривалість кожного виділеного завдання та враховує всі спроби. Технічний і основний бюджети збережено окремо.

У пілоті всі п’ять правил фактично змінювали параметри в чотирьох випадкових початках повністю адаптивного варіанта. Відставання становило 2,2999% для сталого контролю та 4,9780% для спільної адаптації. Пілот не виконував підтверджувального бутстрепу й не змінював правил. В основній серії інтервали обчислено лише для шести наперед визначених контрастів: 50 000 вибірок цілих сімейств, рівень кожного інтервалу 1−0,05/6.

Основна серія дала відставання 2,4927% у сталого контролю, 2,1986% за адаптації турніру та 2,1630% за адаптації елітизму. Для двох останніх правил інтервали ефектів повністю додатні. Правила мутації, популяції та спільне керування погіршили якість; інтервал схрещування охоплює нуль. Всі п’ять параметрів спільного керування змінювалися в 900/900 основних запусках.

Компактні результати та свідоцтво основної повноти містяться в `evidence/main-40205451045-1/`, незмінені пілотні докази в `evidence/pilot-40201292716-1/`. Реєстри ZIP, строки доступності та облік ресурсів збережено поряд. Повні кандидатні журнали до Git не додаються. Пілотний нуль досягнення 99% для контрольної пари у локальному викладі подано таблицею. Основний рисунок 99% зберігає ненульову контрольну криву та всі невдачі спільної адаптації.

Код і компактні докази належать цій дослідницькій гілці. Повні журнали зберігаються окремо. Локальні Word/PDF не публікуються; попередні документи та історичні ядра не змінюються.
