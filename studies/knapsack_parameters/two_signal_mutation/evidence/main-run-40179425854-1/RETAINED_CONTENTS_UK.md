# Збережені матеріали основної серії

Усі вихідні JSON, Markdown та рисунки, крім окремо стисненого масиву записів, мають незмінні байти CI. `ci_file_manifest.json` є точним оригінальним маніфестом артефакту; його назву змінено тільки для розрізнення оригінального вмісту й Git-пакування.

`compact_records.zip` містить один `compact_records.json`: 229 547 399 байтів, SHA256 `d88f182159d668f7c79fe6653e44d3a362cb738ff39fb64c4100e5dc340f5560`. Це стискання без втрат для обмеження Git-розміру, не новий розрахунок. Для відновлення оригінального артефакту потрібно розпакувати його в окрему папку разом із файлами, переліченими в оригінальному маніфесті, та повернути маніфесту назву `file_manifest.json`. Цей опис і додаткове ZIP-пакування не були членами вихідного артефакту.

Компактні записи містять усі 2700 ідентичностей, кінцеві показники, часові ряди популяції й контролера та чисельники операторних показників. Повні журнали кандидатів до Git не включені: вони збережені в десяти CI-артефактах і локальному доказовому архіві. Окремі контрольні суми й ресурсні квитанції наведено поруч у `main_provenance.json`, `main-resource-final.json` та `technical-resource-final.json`.
