# Перевірка після рецензування

Каталог ізольовано від історичного модуля та пошукового виконавця. Новий аудит зчитує лише наявні ZIP; не має команд ГА чи розв'язування задач. Стан реалізації: підготовка, незалежні CI-перевірки та повне звіряння походження ще не виконані.

Середовище: CPython 3.12.14, NumPy 2.2.6; повний зафіксований набір `requirements.lock` призначено для Linux CI. Відтворення в іншому середовищі потребує сумісних пакетів та перевірки хешів; один Linux wheel не є універсальним lock для всіх платформ.

```text
python -m studies.knapsack_parameters.tournament_feedback_review audit --bundle КАТАЛОГ_ZIP --scope smoke --output КАТАЛОГ_ЗВІТУ
```

`full` передбачає 6356 журналів; `smoke` сім. `INVALID` означає помилку даних, `INCOMPLETE` пропуски. Короткий режим не підтверджує повноти всієї серії. Звіт явно фіксує, що бутстреп не перерахований. Ця версія ще не звіряє незалежно походження кожного банку, seed та всі компактні підсумки; тому не подавати її як завершений переносний комплект.

Вихідний KPLIB має атрибуцію в `NOTICE_DATA_UK.md`; ліцензія дослідницького коду та місце довготривалої публікації не встановлені. Публікацію не виконано.
