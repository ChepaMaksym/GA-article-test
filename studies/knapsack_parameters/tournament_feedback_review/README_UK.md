# Перевірка після рецензування

Каталог ізольовано від історичного модуля та пошукового виконавця. Новий аудит зчитує лише наявні ZIP; не має команд ГА чи розв'язування задач. Стан реалізації: підготовка, незалежні CI-перевірки та повне звіряння походження ще не виконані.

Середовище: CPython 3.12.14, NumPy 2.2.6; повний зафіксований набір `requirements.lock` призначено для Linux CI. Відтворення в іншому середовищі потребує сумісних пакетів та перевірки хешів; один Linux wheel не є універсальним lock для всіх платформ. Локальний ZIP містить каталог `bundle` і пакет `studies`; його слід розпакувати в новий каталог, створити окреме середовище з указаними версіями та запустити команду з кореня розпакованого комплекту.

```text
python -m studies.knapsack_parameters.tournament_feedback_review audit --bundle bundle --scope smoke --output report
```

`full` передбачає 6356 журналів; `smoke` сім. `INVALID` означає помилку даних, `INCOMPLETE` пропуски. Короткий режим не підтверджує повноти всієї серії. У корені каталогу `bundle` потрібен `main_compact_records.json.gz`, а для повного режиму також `pilot_compact_records.json.gz`: їхні хеші закріплено в коді. Аудит звіряє seed із початковими станами генераторів, спільні початки, донорський розклад, контрольні суми, кінцеві рекорди і події рекорду; інші компактні показники та бутстреп повторно не обчислюються. CI 41073472174 перевірив короткий режим у відокремленому каталозі без авторських змінних середовища. Повний переносний аудит та звірка всіх підсумків залишаються незавершеними.

Вихідний KPLIB має атрибуцію в `NOTICE_DATA_UK.md`; ліцензія дослідницького коду та місце довготривалої публікації не встановлені. Публікацію не виконано.
