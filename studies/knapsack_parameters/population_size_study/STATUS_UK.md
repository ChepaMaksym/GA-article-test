# Стан Частини 3

Підготовлено протокол, розширення спільного ядра, два точні розв’язувачі, незалежний перевіряльник, обробку проміжних станів і робочий процес технічного пілота. Проведено статичний перегляд коду трьома виконавцями. Ресурсний дозвіл нового технічного етапу не отримано. Тестів, точних розв’язувань, пілотного або основного пошуку цього дослідження ще не виконано. Статичний перегляд не замінює виконання тестів.

Наявність 180 шляхів у зафіксованому Git tree KPLIB підтверджено. Аудит сирих байтів, дублікатів та оптимумів не завершений. Вибраних популяцій для 100, 200 і 500 предметів немає.

Дослідження не є відтворенням результатів статей. Формула представлення бітів виводиться для визначеної схеми ініціалізації; irace використовується як зовнішній метод налаштування. Історичні негативні результати й Частину 2 збережено.
