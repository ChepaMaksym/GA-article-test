# Джерельні підстави

1. Eiben A. E., Smit S. K. Parameter tuning for configuring and analyzing evolutionary algorithms. Swarm and Evolutionary Computation. 2011. Vol. 1. P. 19–31. DOI: 10.1016/j.swevo.2011.02.001. Повний текст: https://staff.fmi.uvt.ro/~daniela.zaharie/am2016/proiecte/tehnici/statistical_analysis/parameter_tuning.pdf. Використання: відокремлення конфігурації алгоритму, вимірювання якості та налаштування; дослідження стійкості. Власних оптимальних значень популяції для наших рюкзаків джерело не надає.

2. Jiménez Laredo J. L., Fernandes C., Merelo J. J., Gagné C. Improving genetic algorithms performance via deterministic population shrinkage. GECCO 2009. P. 819–826. DOI: 10.1145/1569901.1570014. Авторський препринт arXiv:2401.12121v1 розміщено 22 січня 2024 року: https://arxiv.org/pdf/2401.12121. Перевірено повний текст і примітку про первинну публікацію 2009 року. Бісекція оцінки початкової популяції застосована до selectorecombinative GA без мутації та спеціальних trap-функцій. Критерій 49/50 успіхів, поріг 1/16 і схема скорочення не переносяться до нашого алгоритму. Для рюкзака не припускається монотонності якості за μ; бісекція не використовується.

3. López-Ibáñez M., Dubois-Lacoste J., Pérez Cáceres L., Birattari M., Stützle T. The irace package: Iterated racing for automatic algorithm configuration. Operations Research Perspectives. 2016. Vol. 3. P. 43–58. DOI: 10.1016/j.orp.2016.09.002. Повний текст: https://www.econstor.eu/bitstream/10419/178265/1/1-s2.0-S2214716015300270-main.pdf. Документація: https://mlopez-ibanez.github.io/irace/. Перевірено первинний опис, налаштування числового цілого параметра та логарифмічне семплювання. Версія CRAN 4.5.1, дата пакування 2026-10-29; Git blob DESCRIPTION 95893cf8484cb3206963ee3e7fdb0322814ffe15. R та повні залежності потребують окремого фіксування перед калібруванням. Пілот не запускає irace та не вибирає переможця.

4. KPLIB, commit c5bea0df8169749caaba5ce7dfcf21437aa1ca5c: https://github.com/likr/kplib/tree/c5bea0df8169749caaba5ce7dfcf21437aa1ca5c. Через Git trees API отримано повне дерево з truncated=false. Відібрані 180 шляхів і Git blob SHA1 наведено в source_tree_manifest.json. SHA256 сирих байтів і ліцензія README перевіряються окремою CI-підготовкою. Сам факт існування шляху не є допуском до пошуку.

5. COCO: The Experimental Procedure: https://numbbo.github.io/coco-doc/experimental-setup/. Використання: розмежування якості за сталих витрат та витрат до заданої якості. Це методологічне зіставлення; набори безперервних функцій COCO та рекомендації рестартів до нашої задачі не додаються.

Формула (1-2^(-(μ-1)))^n є безпосереднім наслідком незалежної рівноймовірної ініціалізації з одним порожнім вектором. Вона не запозичується як гарантія роботи ГА. Імовірність початкового представлення, ймовірність отримання допустимого набору та ймовірність досягнення оптимуму є різними величинами.
