# Походження версії ядра

Файли `ga_core/*.py` походять із локально збереженої версії
`studies/knapsack_parameters/crossover_population/program/ga_core/`.
Історичні файли не редагувалися. Контрольні суми обох версій
мають входити до зафіксованого маніфесту дослідження до виконання CI.

Один активний цикл у `engine.py` обслуговує всі сталі конфігурації.
Новий контракт `fixed-mutation-grid-v1` дозволяє явно задавати скінченну
сталу ймовірність побітової мутації в межах [0, 1]. Обмеження старих
контрактів, оператори, порядок випадкових викликів та правила завершального
неповного покоління збережені. Контролер записує події, але не змінює
зафіксовані параметри.

Журнали нового контракту мають схему
`ga-knapsack-fixed-mutation-grid-log-v1`. Зміна схеми та назви контракту є
навмисною. Для сумісності старі виклики перевіряються без цієї зміни,
а траєкторії нового контракту за мутації 1/n порівнюються зі старими
після вилучення лише часових спостережень і назви нового формату.

Незалежний перевіряльник у `../verification.py` походить із
`crossover_population/verification.py`, але не імпортує оператори,
контролери, оцінювач або допоміжні функції генераторів виробничого ядра.
Спостереження в `../observations.py` відновлюються після пошуку;
точний оптимум передається лише зовнішній обробці.

Код підготовлено для виконання через GitHub Actions. До окремого
ресурсного дозволу тести, пошук і числову обробку не запускати.
