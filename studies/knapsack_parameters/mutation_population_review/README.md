## Інтерфейс і послідовність

Окремий workflow `knapsack-mutation-population-review.yml` приймає єдиний маркер `[mutation-population:review]` у коміті поточної гілки. Точний SHA, незмінні залежності й окремий ресурсний дозвіл перевіряються перед роботою. Без `explicit_user_approval: true` gate завершується блокуванням. Не запускати workflow з маркером до погодження.

Команди `driver preflight --output ...`, `driver review --permit ... --output ...`, `driver render-saved --permit ... --output ...` та `driver target93 --permit ... --output ...` призначені тільки для зареєстрованого CI. Історична фаза review перевіряє всі 28 800 джерельних ідентичностей, відбирає 3600 попарних записів, відновлює чотири журнали незалежним verifier і будує шість рисунків. Фаза render-saved спрощує рисунок із незмінного перевіреного зведення. Поточний workflow викликає target93 для описового доповнення. Пошукове ядро не імпортується й не викликається.
