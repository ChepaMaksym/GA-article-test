# Додатковий поріг 93% OPT

Доповнення GA-KNAPSACK-MUTATION-POPULATION-TARGET93-V1 до завершеного описового аналізу. Поріг запропоновано користувачем після перегляду результатів; він є вторинним описовим, не новою первинною перевіркою переваги.

З незмінних compact_records.json.gz серії run 40205451045 відновити перший q для 100Vbest(q)>=93OPT. Використати всі 3600 записів профілів 0,1,4,5, задач s020–s029, seeds 97001–97030, початку bank. Відомий початок q=0 та останній новий запит q=5000 враховуються. Недосягнення зберігаються як None; для обмеженого середнього часу їм відповідає 5000, але вони не стають успіхами.

Послідовність усереднення: повторення, задачі сімейства, десять сімейств із рівною вагою. Поруч показати 95%,99% і кінцеве відставання. Для 95% і 99% незалежно відновлені значення мають узгодитися з історичними зведеннями. Нових p-значень, бутстрепу, порогів чи вибору сприятливих прикладів немає. OPT недоступний пошуку; нового пошуку та повторного розв'язування задач немає.

Джерело та його SHA256 залишаються прив'язаними authority.py. Числа 93% ще не обчислені під час реєстрації. Нові матеріали містять окрему криву 93% зі шкалою 0–100%, абсолютні кількості й обмежений середній час до цілі. Старі графіки 95%,99% і якість не замінюються.
