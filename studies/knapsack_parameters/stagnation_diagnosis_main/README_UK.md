# Основна серія дослідження застою

Питання: чи може тривала відсутність покращення поєднуватися з наявністю
кращого допустимого одно- або двобітного сусіда збереженого рекорду?

Окремий дозвіл користувача: 900 запусків, до 200 runner-хвилин та 8 GiB.
Науковий дизайн попереднього протоколу не змінено. Початки вже зафіксовані.
Технічні проби не входять до основної частоти. До основного виконання
потрібні зелені CI-перевірки й зафіксований точний хеш нового виконавця.

Новий сусідній модуль потрібен, щоб не змінювати незмінну авторизацію
технічного етапу, його код, workflow та доказові хеші. Ядро ГА, незалежний
перевіряльник пошуку й діагностика імпортуються без змін. Власних нових
операторів або адаптації немає.

У run 39465168708 пройдено 185 перевірок без помилок і пропусків.
Точний перевірений fingerprint зафіксовано до основного запуску.
Технічну реалізацію та 903 початки не змінено. Наукові результати
основної серії ще не отримано. Маркери нового workflow:
`[knapsack-stagnation-main:tests]` та `[knapsack-stagnation-main:main]`.
Змішані або невідомі маркери відхиляються. Невідомі ресурсні витрати,
змінені хеші чи неповні дані блокують завершення. Історичні результати,
main, PR19 і попередні документи не змінюються.
