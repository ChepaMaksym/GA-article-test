# Різноманітність популяції та продуктивність схрещування

Наукова основа окремого дослідження в межах теми «Дослідження еволюційних генетичних алгоритмів». Дата аудиту: 11 жовтня 2026 року.

Питання: коли генетично різні, але рівноцінні батьки створюють корисних нащадків і як обмеження допустимості змінює цей зв'язок?

## Матеріали

- [Наукова основа](SCIENTIFIC_BASIS_UK.md): постановка, гіпотези, математичні висновки та навчальний контрприклад.
- [Аудит джерел](SOURCE_AUDIT_UK.md): стаття → код → наша зміна → наслідок; попередники та межі новизни.
- [Проєкт протоколу](DRAFT_PROTOCOL_UK.md): три методи зі спільним `(μ+1)` ядром, правила оцінювання й майбутні перевірки.
- [Реєстр джерел](sources.json): бібліографія, версії, ліцензійні межі та SHA256 доступних джерельних файлів.
- [Походження історичної основи](provenance.json): незмінні входи й сертифікати попереднього дослідження, без копіювання доказових каталогів.

## Стан

`FOUNDATION_AND_DRAFT_ONLY`: підготовлено документальну основу; експериментального ядра, виконаних перевірок нових методів, пілота й наукових результатів цієї серії немає. Проєкт `GA-DIVERSITY-CROSSOVER-DRAFT-V1` не є остаточною реєстрацією підтверджувального експерименту.

Гілка: `research/masters-ga-diversity-crossover`. Початкова версія: `7c85f69e390384067a438364b6a325db87e63c0c`. Попередні файли й результати успадковано без змін. Новий напрям не є продовженням старого реєстру реплікацій і не змінює його невдалих результатів.

Аудит виявив прямого попередника: Opris–Antipov, 2026, про добір максимально віддалених батьків. Тому новизною не оголошуються ні такий добір, ні повторне схрещування. Потенційний внесок звужено до контрольованого зіставлення продуктивності нащадків, допустимості й витрат на заданих задачах.

Word, локальна текстова копія, завантажені статті та журнал розміщуються поза робочим деревом, у `Магістерська_різноманітність/Етап_1/`. Наукових обчислень локально не виконано; майбутні тести, статистика й графіки дозволені лише в GitHub Actions після окремого погодження наступного етапу.
