Джерело придатне для літературного огляду. Рішення не спростовує статтю, не перевіряє її опубліковані числа й не доводить неефективності адаптації. Неоднозначності не виправлено приховано. Для іншого джерела або власної модифікації потрібне окреме рішення користувача.
