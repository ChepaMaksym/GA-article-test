## Критерій допуску контролера

До коду потрібні: законний повний текст; точні формули й одиниці керованого параметра; межі, коефіцієнти й початковий стан; момент оновлення; визначення успіху, нічиєї, застою та плоскої популяції; правила для недопустимих наборів; версія й ліцензія доступного авторського коду або явна відсутність коду.

Окремо перевірити рівень керування: одна ймовірність для всього покоління чи окремі ймовірності для особин. Перетворення індивідуальних правил на глобальний контролер є нашою зміною. Рекорд, перевага над батьком, середня якість і допустимість — різні визначення успіху, їх не можна підміняти.

Будь-яку зміну для рюкзака потрібно позначити як нашу проєктну зміну, а не приховане виправлення статті. Власний контролер можливий тільки як окремо погоджена модифікація, без твердження про реплікацію чи новизну наперед.

**Висновок аудиту:** підтверджено існування відповідних сучасних університетських праць, але ще не допущено конкретну пару правил для незалежної адаптації p_m та p_c у визначеному поколіннєвому ГА. Це прогалина наступного етапу, не висновок, що відповідних методів у літературі немає.
