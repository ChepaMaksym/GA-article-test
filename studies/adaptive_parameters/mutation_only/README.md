# Звичайний ГА з адаптацією лише мутації

Окреме нове дослідження за прямим дозволом користувача на власне правило. Не змінює попередні джерельні недопуски, алгоритми чи результати.

- [Проста математика](MATHEMATICS_UK.md): мутація, схрещування, популяція та межі висновків.
- [Зареєстрований протокол](PROTOCOL_UK.md): точне правило та умови майбутнього технічного пілота.
- `engine.py`: поколіннєвий бінарний ГА, популяція 30, схрещування 0,9, одна еліта. Відмінність двох методів — лише зміна мутації.
- `verifier.py`: незалежне відновлення операторів, оцінок, популяцій та контролера.
- `driver.py`, `contract.py`: лише CI, точні SHA, контрольні суми, ресурсні межі та окремий дозвіл на пілот.

Правило: після 5 повних поколінь без нового рекорду мутація подвоюється; після строгого поліпшення зменшується вдвічі. За n=100 межі — 1–8%. Константи проєктні, не оптимальні та не запозичені як готовий доведений контролер зі статті.

Реалізація пройшла **29/29 CI-тестів**: [стан і докази](STATUS_UK.md). Реальні порівняльні результати нового ГА не можна підміняти результатами попередніх серій. Пілот потребує окремого погодження ресурсу; наукова перевага не встановлена.
