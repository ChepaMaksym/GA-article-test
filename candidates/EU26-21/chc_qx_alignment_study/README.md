# CHC-QX: простежуваність та природні стани пошуку

Окрема описова серія. [Допуск](ADMISSION_UK.md),
[протокол](PROTOCOL_UK.md), [машинний контракт](protocol.json),
[стаття → код → зміна → наслідок](TRACEABILITY_UK.md).

Реєстрація до реалізації: `b5c46e603838c5fbc7e35b121f757421c222046f`.
SHA256 протоколу: `c51cbad33d2012b504312e70ff180f7f35cc58ffbd079882acf596b17710de40`.

Поточний стан: реалізацію завершено; preflight на
`0cf349330ea5b9f20e9b758ebe3b3d4475527d19` пройшов 463 тести,
авторський еталон із фіксованими випадковими значеннями й часом та
перевірку точних джерельних ID.
[Перевірка](https://github.com/ChepaMaksym/GA-article-test/actions/runs/37442126611).
Нових числових результатів ще немає. Наступний крок — окремий запуск
на точному SHA, підготовка й фіксація всіх 30 випадків, пошук і звіт.

Перші передпускові збої стосувалися застарілого переліку workflow та
службового `report.log`, який PySwarms створює під час імпорту вихідного
коду. Використано штатний `LOG_CFG` з консольним журналюванням, без
зміни авторських операторів або послаблення перевірки чистоти.
Три методи: CHC із QX, адаптивний λ із QX, сталий λ=1 із QX.
Код еталона отримують у CI за зафіксованою авторською версією.
Попередні алгоритми, результати та протоколи не змінюють.

Усі команди наукового виконання призначені тільки для GitHub Actions.
Звичайний push запускає перевірки, а не матрицю Census. Окремий
SHA-зв'язаний workflow_dispatch запускає підготовку, фіксацію реєстру,
пошук і завершальну агрегацію. Повні моделі не комітять.
Повторюють тільки інфраструктурно невдалі jobs, з тією самою підготовкою;
повтор усієї успішної підготовки після початку пошуку заборонений.
Проміжний стан кожного завершеного блоку записують окремо; він не
замінює завершеного пакета. Запуск, перерваний обмеженням часу CI,
не приймають як природну зупинку алгоритму.

Діагностика перевіряє однобітний окіл, не всі 2^40 масок. Повна функція
означає дерево на всій внутрішній навчальній частині, а не знання
правильного доходу для будь-якої людини. Тестовий файл оцінює лише
фінальні маски. Перевагу за швидкістю чи виходом із максимуму ця серія
не встановлює; нерівні траєкторії не подовжуються штучно.
