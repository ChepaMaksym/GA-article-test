# EU26-02 — AHEAD/Deleter verification

Paper: *A Memetic Algorithm with Adaptive Operator Selection for Graph
Coloring* (EvoCOP 2024), DOI
[`10.1007/978-3-031-57712-3_5`](https://doi.org/10.1007/978-3-031-57712-3_5).

Status: **`ARCHIVE_AND_FORMULA_VALIDATION_ONLY`**

Published-paper status: **`BLOCKED_MULTIPLE_SOURCE_CONFLICTS`**

This candidate is direct graph-coloring optimization with 121–4000 vertex
decision variables in the reported GCP table. The AHEAD configuration adapts
which crossover/local-search pair is used while a run is in progress.

The official archive can be mapped exactly to all 31 AHEAD+Deleter rows in
Table 2, but its CSV headers and the official job generator use 10,800 seconds
per target attempt. Section 3.1 of the paper says one hour per independent
run. The paper's last-50-example update and phase order also differ from the
frozen code's lifetime mean and phase order, while archived `restart` records
cannot be generated by that revision. The validation therefore has two named
time profiles and cannot claim a full paper reproduction:

- `artifact_actual_10800`: exact archive-to-table provenance check;
- `paper_claimed_3600_diagnostic`: a row-level cutoff diagnostic, not a
  reconstruction of a one-hour run.

The frozen v1 contract and pre-run v1.1 source-audit amendment are in
`preregistration/`. The 62 MB upstream archive
is not vendored; every formal replay must acquire the exact pinned object and
verify its SHA-256 before parsing it.

Passing this directory's tests establishes the Deleter transition semantics,
the archive parser, and deterministic parallel aggregation. It does not
resolve the protocol, formula, implementation-revision, or environment
conflicts and must not be reported as `PASS_FULL`.
